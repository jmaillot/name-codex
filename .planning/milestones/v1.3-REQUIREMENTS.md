# Requirements: Name Codex — v1.3 Developer Portal UI

**Defined:** 2026-08-23
**Core Value:** The generated name must always reflect the selected convention — correct segments, correct ordering, correct validation — so a user can copy a compliant, governance-scored name with confidence.

## v1.3 Requirements

Reskin + layout restructure into an Azure Portal / Fluent-inspired developer-portal experience with zero behavior change.

### Theming

- [x] **THEME-01**: Fluent-style dark theme via semantic CSS custom-property tokens — navy layered surfaces (no pure black), off-white text, single accent color; a future light mode is a token swap only *(Complete 2026-08-23 — all 3 Phase 8 plans shipped: tokens.css (08-01), surface repaint (08-02), controls/accent/status/category repaint + legacy teardown + check:tokens gate (08-03); Groups/Intune icon token values UI-SPEC-compliant but visually inert vs hardcoded SVG brand fills — accepted as-is)*

### Layout

- [x] **LAYOUT-01**: Top command bar — app title/version, global search, language switcher, primary actions
- [x] **LAYOUT-02**: Collapsible left rail navigation for convention categories; collapse state persists across sessions *(Outcome: Adjusted — user-approved 09.1 fix (82a1ea8) removed the collapsible rail entirely; NavPanel permanently expanded at 280px; no toggle or persistence key shipped. Validated as the better layout during live review.)*

### Developer-Portal Details

- [x] **DETAIL-01**: Monospace styling for name patterns / generated names / policy IDs; denser panel spacing *(Outcome: Validated 2026-08-24 — mono on core-3 targets via var(--font-mono), density cut sheet landed exactly (10-01); visual confirmation in 18/18 smoke matrix.)*

### Safety

- [x] **SAFE-01**: Zero behavior change — all 137 tests pass, build + lint green, PERF-01..03 intact, EN/FR parity maintained *(Outcome: Closed 2026-08-24 — workflow-8 drift found by honest smoke record (D-12), fixed (10-03), full 9×EN/FR matrix re-run approved by user (10-04); VERIFICATION passed 10/10.)*
