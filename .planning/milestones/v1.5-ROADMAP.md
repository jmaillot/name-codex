### 🚧 v1.5 Naming Convention Expansion (Phases 13-15)

**Goal:** Grow the convention catalog from 25 conventions across 7 categories to 45 across 11 categories — every new convention grounded in official Microsoft standards (CAF, learn.microsoft.com research in `.planning/research/SUMMARY.md`) and shipped as data-driven JSON only (zero code changes), with full EN/FR parity.

#### Phase 13: New Microsoft 365 Categories — Teams, SharePoint, Power Platform, Purview

- [x] **Status:** Complete
- **Requirements:** TEAMS-01, TEAMS-02, TEAMS-03, TEAMS-04, SPO-01, SPO-02, SPO-03, PP-01, PURV-01, PURV-02, PURV-03, PURV-04 (12 requirements → 12 new conventions + 4 new categories)
- **Goal:** Add four brand-new category directories under `src/rules/` (plus segment catalogs under `src/data/segments/`) so users can build governed names for Microsoft Teams, SharePoint sites, Power Platform environments and Purview compliance objects — all discoverable at build time via the existing JSON glob, no code changes.

| # | Deliverable | Success Criteria |
|---|-------------|------------------|
| 13a | Teams category | 1. User can select "Microsoft Teams" in category navigation and build project-team (`PRJ-`), department-team (`DEPT-`) and service-team (`SRV-`) names with ≤30-char maxLength validation (TEAMS-01..03). 2. User can build an Entra naming-policy-format name `GRP_[GroupName]_[Department]` with attribute-token segments and a blocked-words tip (TEAMS-04). |
| 13b | SharePoint / OneDrive category | 3. User can build group-connected Team-site (`/teams/<url>` lowercase-hyphenated guidance), Communication-site (`/sites/<url>`) and Hub-site (`<Function> Hub`) names (SPO-01..03). |
| 13c | Power Platform category | 4. User can build an environment name per ALM strategy `<lifecycle>-<region>-<bu>-<purpose>` with sandbox-vs-production type noted (PP-01). |
| 13d | Purview category | 5. User can build sensitivity-label names from the classification taxonomy with sublabel support (PURV-01), retention-label names with immutable-after-save/no-double-quotes tips (PURV-02), retention-policy names with 7-day lead-time tip (PURV-03), and DLP-policy names with audit-persistence tip (PURV-04). |

**Watch-outs from research:** group-connected site names share the Entra group naming policy (one convention backs TEAMS-04/SPO-01 guidance); Purview retention label/policy names are immutable after creation — tips must emphasize pre-validation.
