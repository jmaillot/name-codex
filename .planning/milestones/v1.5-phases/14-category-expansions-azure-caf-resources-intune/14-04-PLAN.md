Fix major UAT gap (test 6): Autopilot device names offer no budget-aware macro behavior. With prefix+random variant and Prefix `DT-`, all of %RAND:1%–%RAND:15% remain selectable although DT- + 15 randoms expands to 18 chars (> Windows' post-enrollment 15-char limit); switching to PREFIX+RANDOM leaves Macro at the global default `%SERIAL%`; validation counts typed characters only.

Purpose: The user explicitly asked to make %RAND:number% smaller when a prefix like `DT-` is set, so the template is strict against the 15-character budget, and flagged that PREFIX+RANDOM wrongly defaults to SERIAL.

Output: Per-variant RAND default, budget-filtered macro dropdown, prefix-reactive clamp, expansion-aware validation — plus refreshed EN/FR tip/description wording.

Root cause evidence: `.planning/debug/autopilot-rand-not-budget-aware.md` (CONFIRMED: static-only pipeline, zero length/expansion logic anywhere).

</objective>

         const m = /^%RAND:(\d+)%$/.exec(value.trim());

       export function expandedLength(value: string): number | null {
